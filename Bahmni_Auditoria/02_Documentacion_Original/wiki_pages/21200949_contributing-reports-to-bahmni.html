Contributing Reports to Bahmni

  1. If you want a new report on OpenMRS database. Lookup the documentation for it and find out if there are existing canned reports which may meet your requirements.
  2. If you feel that a canned report almost meets your requirements except for something minor, then contact the development team and let them know
  3. If existing canned reports do not meet your requirements then do the following
    1. Create a custom sql report
    2. If you feel this could be canned report (even if you are not sure) send us your custom sql report configuration
    3. The development team evaluates the SQL
      1. If it is a candidate for canned report then your SQL would be used to create one
      2. You would receive a communication about how to replace your custom SQL report with this canned report
