Radiology

About the Feature

Bahmni supports two ways of managing Radiology workflows:

  • Via Manual Radiology Upload

  • Using PACS Integration*

*Picture Archiving and Communication System (PACS) is a medical imaging technology which provides storage and convenient access to radiology  images from multiple imaging equipments. The images are transmitted digitally from the imaging devices and can be seen using a DICOM image viewer which could be native or web based.

Used By

The orders are usually placed by doctors and sometimes by other staff on behalf of the doctor based on pre-decided protocols. The radiology images are seen by Doctors for diagnostic purposes. 

How is it Used?

Bahmni supports both PACS integration and manual upload of radiology images. Please refer to the links below for the steps involved in managing Radiology workflows using Bahmni.
