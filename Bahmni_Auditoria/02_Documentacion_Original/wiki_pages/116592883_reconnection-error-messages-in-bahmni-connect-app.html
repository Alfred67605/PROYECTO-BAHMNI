Reconnection error messages in Bahmni Connect App

When Bahmni Connect app is set up and user is not in network or disconnected, the app starts giving message 

"Reconnect Failed.
Reconnecting in xx seconds..."

This is a configuration which was designed for Online usage and to alert users when they lose connection to save effort. For Bahmni Connect app, it is recommended to turn this flag OFF by setting parameter "showNetworkStatusMessage" to false. Refer to this documentation on Network Status Alert on how to manage this flag.
