Shortcuts in Bahmni

Purpose and Benefits

Enable quick navigation within Bahmni applications.

Shortcuts in Bahmni Modules

Bahmni UI has custom shortcuts. The combination of CTRL and ALT differs from browser and the operating system

 

To use the shortcuts, press the respective key suggestions mentioned above along with the access key. For example: Using Mac and Chrome browser, the shortcut for navigating to home page from clinical dashboard is [Control] [Alt] + H

Listed below are the characters used as access keys in different modules of Bahmni.

Avoid Keys which are reserved by Browsers

If Google Chrome is your browser of choice (or may be used by EndUsers) for accessing Bahmni, refrain from using keys "E" ,"D" and "F" for configuring shortcut keys. "Alt + E" and "Alt + F" is used by Chrome itself for opening up its options and therefore Bahmni will not be able to execute any shortcuts if the same characters are used. Similarly, depending on your browser, please check which keys are already being used.
