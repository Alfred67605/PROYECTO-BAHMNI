Configure CSV Import

Purpose and Benefits

This guide helps the implementers to migrate the existing data that is maintained at a hospital prior to using Bahmni.  The data could be patient information, relationship information, observations, forms, encounters, lab results, drugs and reference terms.  The import is done using CSV files. This functionality is available as part of the Admin module which is available Out Of the Box with Bahmni. However the user needs to have "app:admin" privilege to be able to access it.


Sample CSV formats for Data Import

You can see some sample import CSV file formats in github here: https://github.com/Bahmni/banyan-config/tree/master/openmrs/referencedata
