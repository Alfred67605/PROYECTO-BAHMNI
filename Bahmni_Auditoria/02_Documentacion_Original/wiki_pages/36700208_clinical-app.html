Clinical App

Description

The Clinical App contains configuration for the Clinical Module.

The configuration files should be under bahmni_config/openmrs/apps/clinical of your web server. The app configuration needs an app.json, an extension.json, medication.json, dashboard.json, visit.json. Optionally, you could add a formConditions.js and an extension-x.json. Please see the list below for further details about configuring the JSON files.

JSON files in the Clinical App

  • medication.json
  • extension.json
  • app.json
  • visit.json
  • formConditions.js
  • extension-programs.json
  • dashboard.json
