Tips to increase productivity while using Bahmni

There are a few tips that doctors can use to increase their productivity while using the app.

iPAD

  • Set the screen lock limit to maximum. E.g. 15 mins to avoid unlocking for every patient. Don't make it "Never" for security and power saving.
  • Set Bahmni as home page.
  • Keep minimum tabs open for better device/browser/internet speed.
  • Train on how to close unnecessary opened apps. This might come handy while fixing a slow iPAD.
  • Personalise the usage by setting keyboard shortcut for frequently used terms in Bahmni. Each doctor can identify and set his shortcuts.
  • Suggest trying restarting the iPAD when nothing seems to be working.
