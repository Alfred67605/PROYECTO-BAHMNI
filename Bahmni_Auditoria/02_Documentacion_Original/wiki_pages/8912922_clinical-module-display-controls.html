Clinical module display controls

Catalogue of all display UI controls used on dashboard, visit page, consultation and printouts. The idea is to define these reusable controls which can be assembled via code or via configuration. Each of these controls should be configurable based on - Clinical module configuration. Based on the configuration each control should map to a REST resource call.
