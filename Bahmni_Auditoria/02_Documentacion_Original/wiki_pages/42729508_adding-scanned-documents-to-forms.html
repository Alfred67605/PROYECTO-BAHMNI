Adding Scanned Documents to Forms

Purpose and Benefits

Sometimes, we may have to store some documents as part of the forms.  Bahmni supports scanning the documents using a webcam on your device and uploading them in a form.  There are various document types that are supported like jpeg, pdf.  

Steps to configure documents in the form

  1. Create a concept with the concept class as "Image", concept datatype as "Complex" and Handler as "BinaryDataHandler"
  2. Add this newly created concept to any of your existing concept set which represents a form (i.e. this concept set should be part of "All Observation Templates")
  3. View the newly added field in the form.  This field has a "+" button beside the label which will help you upload the images.
  4. The value filled in the form can be seen on the Patient Dashboard corresponding to the relevant Observation Display control.
