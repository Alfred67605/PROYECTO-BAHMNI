OpenMRS configuration


Configuring certain OpenMRS attributes such as users, patient attriibutes, locations, drugs, concepts and concept sets, etc. are required for every installation of Bahmni. Most OpenMRS configuration can be done using the OpenMRS Administration UI.

Administrators can login with the admin user credentials to make necessary changes. 

When OpenMRS starts up, the default admin password will be test. It is advised to change this password immediately in production environments to avoid unauthorised access.
