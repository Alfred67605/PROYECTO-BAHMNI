extension-programs.json

Description

This JSON file is used to configure clinical extensions for programs. It contains entries for Patient Search tabs to configure the Patient Search queues based on programs and it is also used in the Consultation page to configure the tabs in Program Consultation.

Steps

Configure Patient Search Queue

Patient Search queue is displayed on navigating to the Programs module. It contains a list of patient queues based on the configuration. 

The configuration information and details of the json format is same as extension.json. Please refer to extension.json for details.
