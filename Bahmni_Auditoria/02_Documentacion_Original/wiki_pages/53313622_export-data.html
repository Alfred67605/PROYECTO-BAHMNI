Export Data

About the Feature

The CSV export feature is used to export concept data from Bahmni into a CSV file. This data can then be imported into another instance of Bahmni or used for analysis.

Used By

This feature is predominantly used by hospital administrators and implementers.

How is it Used?

On the CSV export page you can enter a concept into the textfield and select one of the options from the dropdown.

CSV Export Screen

After selecting the dropdown item, click the export button. This results in the download of a CSV file with the respective concept data.

Bahmni configuration for each implementation can vary drastically. The screens and workflows may not be constant across all installations of Bahmni.
