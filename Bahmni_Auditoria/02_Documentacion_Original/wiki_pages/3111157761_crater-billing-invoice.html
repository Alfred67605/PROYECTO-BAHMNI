Crater Billing & Invoice

Bahmni integrates OpenMRS with Crater (version 6.0.6), an open source product. Through Crater, you can then manage Customers, Billing, Payments and invoice etc. Before you start using Crater, you need to setup Crater as per your operational needs. This is only meant to be a guide for effectively working with the rest of Bahmni components (mainly EMR).  For comprehensive guide on setup and usage of Crater, please refer to the Crater documentation.

To install crater with Bahmni, please refer to Bahmni Lite Docker installation setup: Getting Started Quickly with Bahmni on Docker


The pages listed below assist you to setup and configure Crater to work effectively in conjunction with Bahmni Clinical functions.
