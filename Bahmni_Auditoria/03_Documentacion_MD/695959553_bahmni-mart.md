Bahmni Mart is now packaged with Bahmni LITE and docker-compose. You can see the demo here: [Bahmni Lite Environments](/wiki/spaces/BAH/pages/3037757441/Bahmni+Lite+Environments). You can try it out locally using docker by following the steps here: [Running Bahmni on Docker](/wiki/spaces/BAH/pages/299630726/Running+Bahmni+on+Docker). You can see a short **DEMO video** here: [https://www.youtube.com/watch?v=IHZR-W7EdNg](https://www.youtube.com/watch?v=IHZR-W7EdNg)**

About 

Bahmni-mart is a Standalone Batch Application based on spring-batch. Bahmni-mart aims to simplify reporting for Bahmni.
