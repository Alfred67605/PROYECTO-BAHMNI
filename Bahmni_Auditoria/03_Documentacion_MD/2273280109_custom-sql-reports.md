# Custom SQL Reports

Please read [Bahmni Reporting Overview](/wiki/spaces/BAH/pages/2270265367/Reporting+Overview+Bahmni) first.

Custom SQL Reports allow writing a specific SQL that executes on MRS, ELIS or Odoo. This will query the database directly. It is only recommended for tricky use-cases / edge cases where generic reports don’t suffice. 

Please read detailed documentation & examples here: [Reporting Overview (Bahmni)](/wiki/spaces/BAH/pages/2270265367/Reporting+Overview+Bahmni#ReportingOverview(Bahmni)-3.CustomSQL)
