## Purpose and Benefits

User can export reports using this configuration for any analysis. User can create filter list and save it for future use.

## Steps

### 1. Login

Login to OpenERP with admin privileges.

### **2. Click on Purchases, Purchase Orders**.

Choose Purchases and then Purchase Order from left side panel as shown in the screenshot below.

Example
 
As an example, we have added Purchase flow, similarly we can export any module report like Sales,Accounting,Warehouse

**Purchase Orders.**
