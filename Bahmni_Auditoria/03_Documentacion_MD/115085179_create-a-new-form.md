# Create a new Form

> **Versión del documento:** v14 (2019-05-06T07:07:33.043Z) | **Autor/Editor:** Sravya Kanagarla

## Purpose and Benefits

Form Builder provides an easy way to create a new form and add the controls which are required into it. This way is more convenient for an implementer to create a form than the standard way of using a JSON file.

**

Forms Directory
 
All the forms are saved in **/home/bahmni/clinical_forms/ **directory. The directory is set as a global property **'bahmni.forms.directory'. **Implementers can change the directory by updating the global property.

## Steps

### 1. Go to Form Builder

Home Dashboard → Implementer Interface → Form Builder

![](https://bahmni.atlassian.net/wiki/download/attachments/115085179/image2017-3-1_14-7-37.png?version=1&modificationDate=1488348458929&cacheVersion=1&api=v2)

**Form builder dashboard**

### **2. Create a New Form**

Click on the *Create a Form *button and enter a name for the new form.

**![](https://bahmni.atlassian.net/wiki/download/attachments/115085179/image2017-3-1_14-30-33.png?version=1&modificationDate=1488349836325&cacheVersion=1&api=v2)**

**Create a form**

### **3. Add Controls and Save the Form**

[Add some controls](https://bahmni.atlassian.net/wiki/spaces/BAH/pages/115085295/Add+Controls) into the form. The new form will be given a version named "v1" automatically. After the form is saved, the *publish *button is enabled.

![](https://bahmni.atlassian.net/wiki/download/attachments/115085179/image2017-3-1_18-30-45.png?version=1&modificationDate=1488364246926&cacheVersion=1&api=v2)

### 4. Publish the Form

Click on the *publish* button, the form will be published into the Bahmni app which means it can be used by the doctor. Once a form is published, it can only be edited directly. To edit a form *after it is published*, please [refer to these steps](https://bahmni.atlassian.net/wiki/display/BAH/Edit+a+published+form).

![](https://bahmni.atlassian.net/wiki/download/attachments/115085179/image2017-3-1_18-32-5.png?version=1&modificationDate=1488364327979&cacheVersion=1&api=v2)
