## About the Feature

Atomfeed Console is useful when you are facing some sync issues with OpenMRS, OpenELIS, OpenERP, Pacs. Issues such as patients not getting created, orders not getting synced, pacs orders not getting synced etc.,
 
The application has been integrated with Bahmni since release 0.86.

## Used By

It is used by the Bahmni/hospital administrator.

## How is it Used?
1.On the home page of Bahmni click on the icon for **AtomFeed Console******
**

![](https://bahmni.atlassian.net/wiki/download/attachments/116201081/image2016-11-14%2011:58:20.png?version=1&modificationDate=1492588673057&cacheVersion=1&api=v2)

  2. On clicking the icon you'll be taken to the application's page

![](https://bahmni.atlassian.net/wiki/download/attachments/116201081/image2016-11-14%2011:59:25.png?version=1&modificationDate=1492588673602&cacheVersion=1&api=v2)

3. For example, if we click on OpenMRS, we'll see the markers in a new page

![](https://bahmni.atlassian.net/wiki/download/attachments/116201081/image2016-11-14%2012:0:26.png?version=1&modificationDate=1492588673831&cacheVersion=1&api=v2)

4. On clicking the **View **button, we can see all the failed events. On this page you can reset the retry count of the failed event.

![](https://bahmni.atlassian.net/wiki/download/attachments/116201081/image2016-11-14%2012:1:12.png?version=1&modificationDate=1492588674059&cacheVersion=1&api=v2)

 
**Bahmni configuration for each implementation can vary drastically. As the screens and workflows are not constant across all installations of Bahmni, we have refrained from prescribing them. **
