## About the Feature

Admin module has features like [CSV Upload](https://bahmni.atlassian.net/wiki/display/BAH/Import+Data), [CSV Export](https://bahmni.atlassian.net/wiki/display/BAH/Export+Data) and [Order Set](https://bahmni.atlassian.net/wiki/display/BAH/Authoring+Order+Sets).

## Used By

Administrator of the hospital uses this feature.

## How is it Used?

Select the Admin module from the home dashboard to use it.

![](https://bahmni.atlassian.net/wiki/download/attachments/53313588/Screen%20Shot%202016-04-15%20at%201.17.27%20pm.png?version=1&modificationDate=1460707743601&cacheVersion=1&api=v2) 

On accessing the Admin module, three options will be available. Please refer to the links below on using them

- [Export Data](/wiki/spaces/BAH/pages/53313622/Export+Data)
- [Import Data](/wiki/spaces/BAH/pages/53313590/Import+Data)
- [Authoring Order Sets](/wiki/spaces/BAH/pages/49545249/Authoring+Order+Sets)
- [Ward Management Admin Console](/wiki/spaces/BAH/pages/712507393/Ward+Management+Admin+Console)
- [View Audit Logs / Patient Data Access Logs](/wiki/spaces/BAH/pages/2241462320/View+Audit+Logs+Patient+Data+Access+Logs)

**

 
**Bahmni configuration for each implementation can vary drastically. The screens and workflows may not be constant across all installations of Bahmni.**
