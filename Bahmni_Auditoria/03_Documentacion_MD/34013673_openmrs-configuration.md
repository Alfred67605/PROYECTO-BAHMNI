# OpenMRS configuration

> **Fuente Oficial:** [Atlassian Confluence Wiki - Bahmni](https://bahmni.atlassian.net/wiki/spaces/BAH/pages/34013673)  
> **Versión del documento:** v16 (2017-04-10T08:59:42.793Z) | **Autor/Editor:** teresa gracias

---

**Configuring certain OpenMRS attributes such as users, patient attriibutes, locations, drugs, concepts and concept sets, etc. are required for every installation of Bahmni. Most OpenMRS configuration can be done using the [OpenMRS Administration UI](https://192.168.33.10/openmrs/admin/index.htm).
 
Administrators can login with the admin user credentials to make necessary changes. 

When OpenMRS starts up, the default admin password will be test. It is advised to change this password immediately in production environments to avoid unauthorised access. 

### OpenMRS configuration

Configuring the types/attribute below will be required for every installation of Bahmni. 

- Users
- Roles and Privileges
- Locations
- Visit Types
- Encounter Types
- Providers
- Patient Attributes
- Address Hierarchy
- Relationships
- Concepts and Concept Sets
- Drugs
- Order Types
- Global Properties
