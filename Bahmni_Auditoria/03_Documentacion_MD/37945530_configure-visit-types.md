Visit types can be added to the system using the Administration UI at [/openmrs/admin/visits/visitType.list](https://local/openmrs/admin/visits/visitType.list)

## Steps

1) Navigate to *OpenMRS, Administration, Manage Visit Types.*

2) Add new visit type.
