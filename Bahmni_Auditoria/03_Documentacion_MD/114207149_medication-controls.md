**List of Medication Controls**

- [Chronic Treatment Chart Control](/wiki/spaces/BAH/pages/114207300/Chronic+Treatment+Chart+Control)
The drugogram or the chronic treatment chart is a display that shows the current drug regimen of a patient enrolled into a treatment which involves a varying set of drugs over the course of the treatment.

- [Drug Order / Treatment Details Control](/wiki/spaces/BAH/pages/98402409/Drug+Order+Treatment+Details+Control)
This control can be configured to view the drug order details (prescription details) for a particular patient.

- [Treatment Display Control](/wiki/spaces/BAH/pages/99123216/Treatment+Display+Control)
Treatment/Drug Order Control can be configured to display all the the prescription or drug order details (for configured number of visits) for particular patient.

- [Treatment Details Control](/wiki/spaces/BAH/pages/114746475/Treatment+Details+Control)
Treatment/Drug Details Control can be configured to display all the the prescription or drug order details (for configured number of visits).

- [Sending prescription to patients](/wiki/spaces/BAH/pages/3152838666/Sending+prescription+to+patients)
## Purpose 

In cases where the patients would require a copy of their prescription, the provider should be able to send the prescription to the patient. 

Currently Bahmni supports sending prescription via email and ability to download the prescription on the provider’s system which can be handed over to the patient after printing.
