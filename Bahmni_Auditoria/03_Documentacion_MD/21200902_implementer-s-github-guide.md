# Implementer's Github guide

> **Fuente Oficial:** [Atlassian Confluence Wiki - Bahmni](https://bahmni.atlassian.net/wiki/spaces/BAH/pages/21200902)  
> **Versión del documento:** v5 (2015-12-30T09:49:11.698Z) | **Autor/Editor:** Ranjan Sakalley

---

The configuration files (both for the UI and reports) for an implementation are version controlled and hosted at [github.com](http://github.com).

When a new build is deployed in the server, the latest set of configuration files are copied to the server from the github repository. Typically the repository is named as:

```
 -config. 
```

For example,

- Possible Health: [possible-config](https://github.com/Bahmni/possible-config) 
- The Banyan: [banyan-config](https://github.com/Bahmni/banyan-config) 

Hence, the Implementer should know basics of GIT and github, so that they could keep the github repository updated with the latest configuration changes. Some links to help understanding how to use these technologies:

- [Installing Git](http://git-scm.com/book/en/v2/Getting-Started-Installing-Git)
- [Git Cheatsheet](http://ndpsoftware.com/git-cheatsheet.html)
- [Learning Git](http://try.github.com/levels/1/challenges/1)
- [Github official help page](https://help.github.com/)
