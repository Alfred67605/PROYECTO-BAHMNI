## Description

OpenMRS provides a mechanism to configure users (add, assign roles, modify) through the Administration screen. [OpenMRS guide](https://wiki.openmrs.org/display/docs/Administering+Users) provides details about the roles and privileges. In this page, description of adding users, assigning roles is elaborated.

## Steps

### Add New User and Assign Roles

- Login to OpenMRS with user having Administrator privileges.
- Navigate to the OpenMRS Administration page and select "Manage Users" link.

![](https://bahmni.atlassian.net/wiki/download/attachments/34013682/Screen%20Shot%202016-03-23%20at%202.45.41%20PM.png?version=1&modificationDate=1458724646752&cacheVersion=1&api=v2)

- Click on "Add User" link.
- Under "Create a new person" label, click on "Next" button.
- In the page which appears, add information about the user.
![](https://bahmni.atlassian.net/wiki/download/attachments/34013682/Screen%20Shot%202016-03-23%20at%202.43.37%20PM.png?version=1&modificationDate=1458724867857&cacheVersion=1&api=v2)

- Assign required roles to the user.
![](https://bahmni.atlassian.net/wiki/download/attachments/34013682/Screen%20Shot%202016-03-23%20at%202.52.41%20PM.png?version=1&modificationDate=1458725015486&cacheVersion=1&api=v2)
- Finally, click on "Save user" button to save the changes made.

## **Making a user as a provider (doctor / clinician / nurse)
**

Perform the following steps to add a user as a doctor/clinician/nurse in Bahmni (they are called *providers*).

- Click on **"Manage Providers" **in the OpenMRS administration page

**

**
![](https://bahmni.atlassian.net/wiki/download/attachments/34013682/2.png?version=1&modificationDate=1476947704741&cacheVersion=1&api=v2)
