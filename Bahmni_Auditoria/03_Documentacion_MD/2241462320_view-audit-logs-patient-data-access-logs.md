# View Audit Logs / Patient Data Access Logs

> **Fuente Oficial:** [Atlassian Confluence Wiki - Bahmni](https://bahmni.atlassian.net/wiki/spaces/BAH/pages/2241462320)  
> **Versión del documento:** v1 (2021-03-15T07:18:58.566Z) | **Autor/Editor:** Gurpreet Luthra

---

Bahmni allows an authorised **Admin** user to view the Audit Logs, which store all patient data view, entry, modification details, to understand if a user/provider accessed patient data that they should not have.

For more details see: [Audit Logs](/wiki/spaces/BAH/pages/115906837/Audit+Logs)
