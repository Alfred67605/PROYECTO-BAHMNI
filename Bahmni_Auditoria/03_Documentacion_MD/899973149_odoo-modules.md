### Compatibility across different versions
Integration with Odoo version 16 is available from Bahmni Standard 1.0.0 (on docker) and it is the supported version going forward.

Odoo 10 is also available on bahmni-docker for implementers to help migrate from 0.93 to latest version with a database backup, but will not receive any updates or security patches and it is recommended to migrate to Odoo 16.

Integration with Odoo version 10 is only available from Bahmni 0.92 version onwards. 

Bahmni 0.91 and earlier works with OpenERP 7. 

Bahmni integrates OpenMRS with [Odoo](https://www.odoo.com/), an open source ERP product. Through Odoo, you can then manage Customers, Billing, Pharmacy and Stock management etc. Before you start using Odoo, you need to setup Odoo as per your operational needs. This is only meant to be a guide for effectively working with the rest of Bahmni components (mainly EMR).  For comprehensive guide on setup and usage of Odoo, please refer to the [Odoo 16 documentation](https://www.odoo.com/documentation/16.0/). Odoo has wonderful webinars, easily available on its Youtube channel.
