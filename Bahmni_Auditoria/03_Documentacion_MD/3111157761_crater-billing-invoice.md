# Crater Billing & Invoice

> **Fuente Oficial:** [Atlassian Confluence Wiki - Bahmni](https://bahmni.atlassian.net/wiki/spaces/BAH/pages/3111157761)  
> **Versión del documento:** v4 (2023-06-15T09:44:48.353Z) | **Autor/Editor:** Gurpreet Luthra

---

Bahmni integrates OpenMRS with [Crater](https://craterapp.com/) (version 6.0.6), an open source product. Through Crater, you can then manage Customers, Billing, Payments and invoice etc. Before you start using Crater, you need to setup Crater as per your operational needs. This is only meant to be a guide for effectively working with the rest of Bahmni components (mainly EMR).  For comprehensive guide on setup and usage of Crater, please refer to the [Crater documentation](https://docs.craterapp.com/).

To install crater with Bahmni, please refer to Bahmni **Lite** Docker installation setup: [Getting Started Quickly with Bahmni on Docker](/wiki/spaces/BAH/pages/3117744129/Getting+Started+Quickly+with+Bahmni+on+Docker)
